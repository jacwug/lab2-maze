About Maze Game

Overview

This is an interactive maze game that demonstrates classic maze generation and pathfinding algorithms. The game generates random mazes and allows you to either solve them manually or watch automated algorithms find the solution.

Features

  • Random Maze Generation: Each time you reset, a new unique maze is created using a recursive backtracker algorithm.
  • Manual Navigation: Use the W, A, S, D keys to navigate through the maze yourself.
  • Automated Solving: Watch as Breadth-First Search (BFS) or Depth-First Search (DFS) algorithms find the solution.
  • Visual Algorithm Exploration: See how the algorithms explore different paths to find the solution.
  • Customizable Size: Adjust the maze size from 5x5 up to 100x100 cells.

How to Play

Manual Mode: Use the keyboard keys W (up), A (left), S (down), and D (right) to navigate the blue player through the maze. Your goal is to reach the green exit square.

Automated Solving: Select an algorithm from the dropdown menu and click "Solve Maze" to watch the computer find the solution. Red highlights show explored cells, and yellow shows the final path.

Algorithms

Breadth-First Search (BFS): Explores the maze level by level, guaranteeing the shortest path.

Depth-First Search (DFS): Explores as far as possible along each branch before backtracking.
